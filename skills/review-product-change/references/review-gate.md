# Two-pass review gate

## Pass 1: specification compliance

- Must-have requirements and acceptance states are implemented.
- Added behavior is in scope and does not contradict non-goals.
- Roles, permissions, responsive behavior, data lifecycle, metrics, and operations match product artifacts.
- Requirement-to-test traceability is complete.

## Pass 2: implementation quality

- Boundaries, invariants, errors, concurrency, compatibility, and migrations are correct.
- Security, privacy, tenant isolation, secrets, and logs are safe.
- Tests fail for meaningful regressions and avoid brittle internals.
- Accessibility, performance, reliability, observability, and rollback are adequate.
- Product meaning, originality, and hierarchy survive implementation without generic AI-generated filler.
- Mobile composition supports the primary task and does not merely stack the desktop layout.
- Diff is scoped and contains no placeholders, debug residue, or unrelated change.

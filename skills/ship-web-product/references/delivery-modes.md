# Delivery modes

Choose one mode and record why. Gates remain risk-based; a mode changes artifact depth, not truthfulness.

## greenfield-product

Use for a new durable product. Require product analysis, PRD, experience design when user-facing, architecture, threat model, delivery plan, test strategy, and deployment readiness.

## brownfield-feature

Use for a feature in an existing product. Start with current behavior and compatibility. Persist feature-scoped requirements, architecture deltas, affected threats, bounded tasks, regression evidence, and rollout impact.

## prototype

Use to resolve product or technical uncertainty. Define the hypothesis, time box, disposable boundaries, evidence, and explicit path to discard or productionize. Never describe prototype controls as production-ready.

## production-hardening

Use when behavior largely exists but security, reliability, accessibility, performance, observability, data lifecycle, or deployment safety is incomplete. Begin with a gap assessment and measurable gates.

## incident-fix

Use for urgent restoration. Prioritize containment, evidence preservation, root cause, minimal fix, fresh verification, safe rollout, and a scheduled follow-up for systemic prevention.

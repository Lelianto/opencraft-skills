# PRD quality gate

Mark each `pass`, `needs decision`, or `not applicable`.

- Problem and target user are supported by evidence or labeled assumptions.
- Outcome has measurable metrics, baseline strategy, and evaluation window.
- Must-have scope forms one usable end-to-end journey.
- Non-goals prevent plausible scope expansion.
- Requirements describe observable behavior and have stable IDs.
- Roles and server-enforced permissions are explicit.
- State coverage includes relevant failure and recovery paths.
- Data collection, retention, deletion, export, and sensitivity are addressed.
- Accessibility, responsiveness, security, performance, reliability, and observability are testable.
- Rollout, migration, support, rollback, dependencies, risks, and open decisions have owners.

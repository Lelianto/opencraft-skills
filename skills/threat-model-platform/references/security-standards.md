# Security standard references

- Pin external control identifiers to a version, for example `ASVS-v5.0.0-<requirement>`.
- Choose an ASVS target level from actual application risk and document the rationale.
- Apply OWASP AISVS only when AI functionality is in scope; pin its version as `AISVS-v<version>-<control>`.
- Keep external standards as references, not copied content. Consult the authoritative source for control wording.
- Record `not applicable` with rationale; never silently omit a selected control.
- A referenced control is not passed until implementation and verification evidence exists.

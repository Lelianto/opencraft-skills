# Firebase pack

Living context for Firebase backends: security rules, Firestore modeling, Cloud Functions, and auth.

## Included contexts

- `ctx-firebase-rules` — Firestore/Storage covered by rules (hardened-mandate, block).
- `ctx-firebase-functions` — privileged work in Cloud Functions (warn).
- `ctx-firebase-modeling` — models around access boundaries (warn).

## Extends

- `typescript-pack@^1`
- `security-pack@^1`

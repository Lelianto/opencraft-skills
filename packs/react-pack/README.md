# React pack

Living context for React applications: component conventions, hooks discipline, and AI coding rules.

## Included contexts

- `ctx-react-functional-components` — function components (warn).
- `ctx-react-hooks-rules` — Rules of Hooks enforced (block).
- `ctx-react-keys` — stable list keys (warn).

## Extends

- `typescript-pack@^1`

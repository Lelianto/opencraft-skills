# 0010 — CLI Integration

**Status:** Candidate · **Version:** 1.0.0 · **Spec:** OpenCraft Skills — Context Packs

## Abstract

Context Packs integrate into the existing `opencraft-skills` CLI under the `packs` namespace. The CLI is dependency-free (Python and Node, behaviorally equivalent) and safe: it never overwrites unmanaged files, never silently resolves hardened conflicts, and never requires network when a cache or built-in tree satisfies the request.

## Command reference

```text
opencraft packs init [--project <dir>]
    Create packs.yaml (project declaration) and a git-backed .lcdd/ skeleton.

opencraft packs add <name>[@range] [--project <dir>]
    Add a pack reference to packs.yaml. Refuses duplicates.

opencraft packs remove <name> [--project <dir>]
    Remove a pack reference from packs.yaml.

opencraft packs install [--project <dir>] [--force] [--resolve <id> <pack>] [--json]
    Resolve, merge, validate, and materialize into .lcdd/. Prefers the lockfile.

opencraft packs update [--project <dir>]
    Re-resolve ranges, write a new lockfile, and materialize.

opencraft packs list [--project <dir>] [--json]
    List declared and resolved packs.

opencraft packs status [--project <dir>] [--json]
    Show effective contexts, PKDs, overrides, and conflicts.

opencraft packs doctor [--project <dir>]
    Health report: stale contexts, missing owners, deprecation backlog, drift.

opencraft packs resolve --dry-run [--project <dir>] [--json]
    Print the resolved graph, precedence, and conflicts without writing.

opencraft packs validate [<pack>|--all] [--project <dir>]
    Validate one pack, the whole packs/ tree, or an installed project.

opencraft packs verify [--project <dir>]
    Integrity-check lockfile hashes.

opencraft packs create <name> [--type <type>] [--dir <out>]
    Scaffold a new pack (manifest, contexts, project/, ai/, evals/).

opencraft packs publish <name> [--registry <url>] [--npm]
    Package, verify integrity, and publish to the npm transport.

opencraft packs lock [--project <dir>]
    Regenerate the lockfile from the resolved graph.
```

Global flags: `--project <dir>` (default `.`), `--json` (machine-readable output), `--force`, `--dry-run`.

## Behavior guarantees

- **Deterministic** output; identical declaration → identical `.lcdd/`.
- **Non-destructive:** files in `.lcdd/` not produced by the engine are left alone; `.lcdd/` regeneration preserves user-local context files under `.lcdd/local/`.
- **HITL-aware:** hardened conflicts and `human` policy pause for an explicit human decision (consistent with the OpenCraft HITL contract). AI recommendations never count as approval.
- **Exit codes:** `0` success, `1` validation/resolution failure with report, `2` usage/IO error.

## JSON output

`--json` emits a single JSON object with `{ok, errors[], conflicts[], overrides[], materialized{...}}` for automation and CI.

## CI integration

The engine is designed to run headlessly:

```yaml
- name: Validate pack tree
  run: python3 scripts/packtool.py packs validate --all
- name: Verify integrity lock
  run: python3 scripts/generate_pack_lock.py --check
- name: Smoke-test install
  run: node scripts/packtool.mjs packs install --project "$(mktemp -d)"
```

# Accessibility pack

Living context for accessibility: WCAG 2.2 AA, keyboard operability, and accessible names.

## Included contexts

- `ctx-a11y-wcag-aa` — WCAG 2.2 AA with automated + manual checks (warn).
- `ctx-a11y-keyboard` — full keyboard operability (warn).
- `ctx-a11y-labels` — accessible names and announced states (warn).

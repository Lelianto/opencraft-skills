# Core pack

The baseline living context applied automatically to every OpenCraft project: evidence standard, secrets protection, production authority, and honest claims. Language-agnostic and installable with zero configuration.

## Included contexts

- `ctx-core-evidence-standard` — completion claims need fresh evidence (warn).
- `ctx-core-secrets-protection` — no committed secrets (hardened-standard, block).
- `ctx-core-production-authority` — human authority for production/destructive/external actions (hardened-standard, block).
- `ctx-core-honest-claims` — no invented metrics or unsupported claims (warn).

## Provenance

- Author: OpenCraft · License: MIT · Source: https://github.com/Lelianto/opencraft-skills

## Usage

Installed automatically by `opencraft-skills install --with-project-files` and `opencraft-packs packs bootstrap`.
